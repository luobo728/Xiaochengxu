# 登录系统说明（微信一键登录）

## 现在是什么状态

**点一下按钮就登录，不用输任何字。**

**本地模式（当前）**：不需要云函数，编译即可用。
一键登录在本地用的是**设备标识**当身份（换手机＝另一个账号），够你先把界面和流程跑通。

**云端模式（后端已写好）**：云开发能直接拿到调用者的**微信身份（openid）**，
所以后端一步就能认出「这是谁」—— 首次点登录自动建账号，之后再点就是登录，无需密码、无需短信验证码。
把 `utils/auth.js` 顶部的 `MODE` 改成 `'cloud'` 即可切换，**页面一行都不用改**。

## 「我的」页的样子

| 状态 | 显示 |
| --- | --- |
| 未登录 | 「家长登录」卡片：**微信一键登录**大按钮（绿色）+ 说明文字 + 次要入口「用姓名·手机号登录 ›」（点开展开备用表单，演示账号姓名 `1` / 手机号 `1`） |
| 已登录（资料未填） | 账号卡片：头像方块显示「微」、名字显示「微信用户」、手机号显示「未绑定手机号」+ 一行「完善资料（姓名与手机号）›」 |
| 已登录（资料已填） | 账号卡片：姓名首字头像 + 姓名 + 手机号 + 登录时间 + 「切换账号 ›」 |

未登录时「孩子档案」「课时与余额」两张卡片会隐藏；账单页有登录守卫（未登录直接退回）。

## 接口（7 个）

| 方法 | 说明 |
| --- | --- |
| `getUser()` | 同步 → `{ name, phone, role, token, wx, isNew, loginAt, loginAtText }` 或 `null`（**有 token 就算已登录**，姓名/手机号可以为空） |
| `isLoggedIn()` | 同步 → 布尔 |
| `wxLogin()` | **微信一键登录** → `{ ok, msg, user }` |
| `updateProfile(name, phone)` | 一键登录后补充姓名/手机号 → `{ ok, msg, user }` |
| `login(name, phone)` | 备用：姓名 + 手机号登录 |
| `logout()` | 退出（云端模式会通知服务端作废 token） |
| `demoAccount()` | 备用登录的演示账号 `{ name: '1', phone: '1' }` |

## 切到云端（页面不用改）

1. 部署云函数 **`auth`**：`cloudfunctions/auth/` → 右键 →「上传并部署：云端安装依赖」
2. 建集合 **`users`**，权限选「仅管理端可读写」（客户端不直接读它）
3. 给 `users` 的 **`openid`** 字段建索引（一键登录按它找人，强烈建议加）
4. 把 `utils/auth.js` 的 `MODE` 改成 `'cloud'`

云函数 action：

| action | 入参 | 返回 |
| --- | --- | --- |
| `wxlogin` | 无 | `{ ok, user, token, isNew }`（按 openid 自动注册/登录） |
| `profile` | `{ token, name, phone }` | `{ ok, user }` |
| `login` | `{ name, phone }` | `{ ok, user, token }`（备用登录，账号需先在 users 里） |
| `me` | `{ token }` | `{ ok, user }`（校验登录是否还有效） |
| `logout` | `{ token }` | `{ ok }` |

`users` 文档字段：`{ openid, name, phone, role, enabled, lastToken, lastLastLoginAt, createTime }`

## 生产前必做

1. **关掉开发用账号**：给云函数 `auth` 加环境变量 `ALLOW_DEV_ACCOUNT=0`（之后 `1/1` 登不进去）
2. **要拿到真实手机号**（用于绑定孩子）时，可加微信官方能力：
   `<button open-type="getPhoneNumber">`（手机号快速验证组件）—— 需要小程序**已认证主体**并在后台开通该能力（**按次付费**），
   拿到 `code` 后由云函数调用微信接口换取手机号。现在没用到，需要时告诉我，我加上。
3. **昵称/头像**：微信已不再允许静默获取，需用户主动授权
   （`<button open-type="chooseAvatar">` + `<input type="nickname">`）。当前版本不采集头像昵称，只用姓名。
