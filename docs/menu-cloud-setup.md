# 怎么上传食谱图片（一步一步照做就行）

一共只要做 **3 件事**，然后就能一直传图片了。
做的时候不用懂技术，照着点就行。每做完一步，我会告诉你「屏幕上会出现什么」，对着看就对了。

---

## 第 1 件事：开通「云开发」

（这是给小程序放图片的地方。免费，不用付钱。）

1. 在电脑上打开 **微信开发者工具**，打开我们这个小程序项目。
2. 看窗口最上面那排按钮，找到 **「云开发」** 三个字，**点一下**。
3. 会弹出一个窗口。
   - 如果它让你「开通」，就点 **「开通」**。
   - 如果它让你给环境起名字，随便写，例如 `youeryuan`，然后点确定。
4. 等几秒钟。

**你会看到**：出现一个云开发的页面（左边有「数据库」「存储」「云函数」这些字）。
看到这些字，就说明第 1 件事做完了。

---

## 第 2 件事：把「云函数」传上去

（这是小程序的大脑，负责判断谁可以传图片。）

5. 回到开发者工具的主窗口，看 **左边那一列文件列表**。
6. 找到 **`cloudfunctions`** 这个文件夹，点它左边的三角箭头，展开它。
7. 里面有一个 **`menuAdmin`** 文件夹。**用鼠标右键点它**。
8. 在弹出来的菜单里，点 **「上传并部署：云端安装依赖」**。
9. 等它转圈，大概 1 到 3 分钟。

**你会看到**：窗口上出现 **「上传成功」** 四个字。
看到这四个字，就说明第 2 件事做完了。

---

## 第 3 件事：把你自己变成「管理员」

（只有管理员才能传图片。这一步一辈子只做一次。）

10. 让小程序停在最下面那条导航的 **「我的」** 页面。
11. 看页面 **最下面那行灰色小字**：「阳光幼儿园 · 家长端 v1.0.0」。
    用手指（或用鼠标）**一直按住它，按住 2 秒不要松手**。
12. **你会看到**：弹出一个窗口，写着「还没有设置管理员」，还问你「要把现在这台微信设置为本园的管理员吗？」
    → 点 **「确定设置」**。
13. **你会看到**：又弹出一个窗口，写着「设置成功」，还有两个按钮。
    → 点 **「去上传」**。

就到这里，全部准备工作结束了。

> ⚠️ 这一步只能做一次：**第一个做的人就是管理员**。
> 所以请你自己先做，不要让别的人先做。
> 以后要给别的老师开权限，让老师长按版本号，把显示的 openid 发给你，再按最后面的附录操作。

---

## 以后每次上传图片

1. 进 **「我的」** 页面 → 找到 **「食谱管理」** → 点进去。
   （如果没看到「食谱管理」，就退回「我的」，再进来一次。）
2. 第一行 **「日期」**：默认是今天。要传别的日子，就点它改。
3. 第二行 **「餐次」**：点 **早餐 / 早点 / 午餐 / 午点 / 晚餐** 里的一个。
   一次只能传一个餐次，一个餐次最多 9 张。
4. 点中间那个 **虚线方框** → 会问你是「从相册选择」还是「拍照」→ 选你要传的图片（可以一次选好几张）。
5. 等上面的字从「上传中 2/5」变成没有。

**你会看到**：方框下面多出了图片的小图（缩略图）。
看到缩略图，就是传成功了。家长这时就能看到了。

- **传错了要删掉**：点图片右上角那个小黑圆叉 → 再点「确定」。
- **家长怎么看**：回去点首页 → 点 **「今日食谱」** → 就能看到你传的图片了。

## 出问题了看这里

| 屏幕上写着什么 | 是什么意思 | 你该做什么 |
| --- | --- | --- |
| 「尚未连接云开发」 | 第 1 件事没做完 | 回去重做第 1 件事 |
| 长按版本号没反应，或弹出「读取失败」 | 第 2 件事没成功 | 回去重做第 2 件事 |
| 「我的」页面里没有「食谱管理」 | 你还不是管理员 | 长按版本号，按提示点「确定设置」 |
| 长按后说「本园已设置过管理员」 | 管理员已经有人当了 | 把弹窗里那串 openid 发给园长，让园长加你 |
| 图片显示成一个空白框 | 网络慢，或图片还在传 | 下拉刷新一下；还不行就重新打开小程序 |
| 传完了，家长说看不到 | 网络有延迟 | 让家长下拉刷新；等 1 分钟再看 |

如果上面都对不上，就把你看到的字截图发给帮你做小程序的人。

# 附录（给懂技术的人 / 以后的自己看，普通使用不用看）

## 权限是怎么保证的
- 客户端（家长端）**没有任何写图片的代码**，只能通过云函数 `list` 读图片。
- 新增、删除都必须经过云函数 `menuAdmin`，云函数用 `getWXContext().OPENID` 判断是不是管理员（身份无法伪造）。
- 第一个管理员来自「一键初始化」：只有 `menu_admins` 集合为空时才允许，设置成功后该集合非空，别人再调 `init` 会被拒绝（`index.js` 的 `hasAdmin()`）。
- 其他管理员来源（二选一）：云函数环境变量 `ADMIN_OPENIDS`（逗号分隔），或 `menu_admins` 集合里文档 ID = openid 的记录。
- 数据库集合用默认权限即可：客户端不直接读库，全部走云函数。
- 云存储用控制台默认权限「所有用户可读，仅创建者可读写」即可：读=家长能看图；写=老师上传的是自己的文件；删除走云函数（不受该规则限制）。

## 数据结构（集合 `menu_photos`）
| 字段 | 说明 |
| --- | --- |
| `date` | `YYYY-MM-DD`，按天查询 |
| `meal` | `breakfast` / `morning` / `lunch` / `afternoon` / `dinner` |
| `fileID` | 云存储文件 ID，`<image src>` 可直接渲染 |
| `sort` | 同餐次展示顺序 |
| `createTime` | 服务端时间 |
| `creator` | 上传者 openid |

餐次名称与时间定义在 `utils/meal.js`（客户端与管理端共用）。

## 云函数接口
| action | 谁能调 | 说明 |
| --- | --- | --- |
| `whoami` | 所有人 | 返回 `{ openid, isAdmin, initialized }` |
| `list` | 所有人 | 入参 `{ dates: [...] }`，最多 14 天、返回最多 100 条 |
| `init` | 所有人 | 仅当还没有管理员时可用，把调用者设为管理员 |
| `add` | 仅管理员 | 入参 `{ items: [{date, meal, fileID, sort}] }`，单次上限 60 条 |
| `remove` | 仅管理员 | 入参 `{ id }`，同时删除云存储文件 |

## 想换成自建后端
只改 `utils/menu.js`（唯一与云开发交互的文件），页面不用动。它导出：
`isCloudReady / cloudError / listByDate / listByDates / groupByMeal / whoami / initAdmin / addPhotos / removePhoto / previewUrls`

## 环境
- `utils/env.js` 的 `ENV_ID`：只有一个云环境时留空即可；有多个环境时填目标环境 ID。
- 客户端读的环境要和云函数部署的环境一致，否则会出现「提示已添加 N 张、列表却是空的」。
