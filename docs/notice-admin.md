# 通知公告（管理员可编辑）—— 对接说明

本模块给**管理员**用：在手机上发布、修改、删除、置顶通知公告；家长端在首页和通知详情页看。

小程序里对应的入口（都要先成为管理员才看得见）：

| 位置 | 说明 |
| --- | --- |
| 我的 → 通知公告管理 | 管理页：新增 / 修改 / 置顶 / 删除 / 恢复演示通知 |
| 首页 → 最新通知 那一条 | 家长看通知详情；管理员在详情页底部多一个「编辑这条通知」 |
| 首页 → 顶部快捷入口「通知」 | 打开最新一条通知的详情 |

代码位置：

- 数据层：`utils/notice.js`（**全项目只有它碰通知数据**，页面只调用它）
- 家长详情页：`pages/notice/notice.*`
- 管理员管理页：`pages/notice-admin/notice-admin.*`
- 云函数：`cloudfunctions/noticeAdmin/`
- 首页读取：`pages/index/index.js`（onLoad 同步读一次，onShow 再刷新一次）

## 一、现在是「本地模式」，马上就能演示

`utils/notice.js` 第 16 行：

```js
const MODE = 'local'
```

本地模式的特点：

- 通知存在**这一台手机**里（`wx.setStorageSync`），不联网也能用，换手机看不到。
- 第一次打开会自动写入 4 条演示通知；管理员点「恢复演示通知」可以还原。
- **家长端各看各的**：因为数据没上云，只适合给园长看演示效果。

### 立刻演示（不用云开发）

1. 打开小程序 → 进「我的」页 → **长按页面最下面那行灰色小字**（阳光幼儿园 · 家长端 v1.0.0）。
2. 云开发还没配好时，会弹「云开发还没准备好」→ 点 **开启体验** → 再点 **去管理**。
3. 进入「通知公告管理」，改一条标题或正文 → 点 **保存**。
4. 回到「首页」→ 通知那三条里立刻能看到你改的内容；点进去就是详情页。

> 想关掉这个体验身份：再长按一次版本号 → 点「关掉」。

## 二、想给所有家长同步看：切到云端（3 步）

### 第 1 步：部署云函数

在微信开发者工具左侧文件树里：

1. 右键 `cloudfunctions` 文件夹 → 先确认已经开通云开发（顶部没有「未选择环境」）。
2. 右键 `noticeAdmin` 文件夹 → **上传并部署：云端安装依赖（不上传 node_modules）**。
3. 等右下角提示上传成功（第一次约 1~3 分钟）。

### 第 2 步：确认管理员名单

管理员名单和「食谱管理」**共用一份**，不用再配一遍：

- 云函数 `menuAdmin` 的环境变量 `ADMIN_OPENIDS`（多个 openid 用英文逗号隔开），或
- 云数据库集合 `menu_admins`，文档 ID 就是管理员的 openid。

还没设过管理员时：在「我的」页长按版本号 → 弹「还没有设置管理员」→ 点「确定设置」，当前微信就成为管理员（这一步走的是 `menuAdmin`）。

### 第 3 步：把数据层切到云端

打开 `utils/notice.js`，把第 16 行改成：

```js
const MODE = 'cloud'
```

然后重新编译。之后：

- 管理员保存的通知会写进云数据库集合 `notices`，所有家长都能看到。
- 家长端读不到云函数时，会自动退回本机缓存的内容（不白屏）。

## 三、云函数接口（`noticeAdmin`）

统一约定：入参都是 `{ action, ... }`，返回 `{ ok: true, ... }` 或 `{ ok: false, msg }`。

| action | 谁能调 | 入参 | 返回 |
| --- | --- | --- | --- |
| `whoami` | 任何人 | — | `{ openid, isAdmin, initialized }` |
| `list` | 任何人 | — | `{ rows: [...] }`（已按置顶、时间排好） |
| `save` | 仅管理员 | `{ id?, title, tag, body, top }` | `{ item }`（无 id = 新增，有 id = 修改） |
| `remove` | 仅管理员 | `{ id }` | `{ removed: 1 }` |
| `reset` | 仅管理员 | — | `{ reset: 4 }`（清空后写回 4 条演示通知） |

一条通知的字段：

```js
{
  id: '文档 _id',         // 客户端用 id 或 _id 都能识别
  title: '4月20日 家长开放日，欢迎家长准时参加',
  tag: '通知',            // 只能是：通知 / 活动 / 保健 / 提示 / 食谱
  time: '04-12',          // MM-DD，新增时云端自动填今天
  body: '正文，用 \\n 分段',
  top: true,              // 是否置顶
  createdAt: 1760000000000,
  updatedAt: 1760000000000
}
```

限制：标题最多 40 字、正文最多 1000 字（前后端都校验）；`list` 一次最多返回 100 条。

**安全**：`noticeAdmin` 里**没有**自助成为管理员的分支，只有 `menuAdmin` 能认领第一个管理员；两个云函数共用同一份白名单。

## 四、常见问题

**Q：长按版本号没反应？**
A：要长按「阳光幼儿园 · 家长端 v1.0.0」这行字，按住 1 秒左右松开。

**Q：点了「开启体验」还是看不到管理入口？**
A：回到「我的」页重新进一次（切到别的 tab 再切回来也行），入口会刷新。

**Q：管理页显示「只有管理员能编辑通知」？**
A：说明当前微信不在白名单里。请园长在手机上看一遍：长按版本号 → 会显示你的 openid → 复制发给园长添加；或按第二节第 1 步重新部署后再长按一次。

**Q：改了通知，首页没变？**
A：从管理页返回时会自动刷新；如果还不对，切到「课时」再切回「首页」，或点右上角「编译」重来一次。

**Q：云端模式报「-501002 超时」？**
A：通常是第一次调用冷启动慢，客户端会自动重试一次。还失败就检查：开发者工具顶部是否「未选择环境」；云函数是否真的上传成功；把云函数超时时间调到 20 秒。
